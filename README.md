# Library-Management-System
A basic Library Management System created using Python classes and objects.

# Project Purpose:
The purpose of the program is to create easier management for a library

# Classes
## In the program I have used three classes:
**Book**
In the Book class I will define attributes of book and display them

**Patron**
In the Patron class I will store patron details and have a way to manage the books they have borrowed

**Library**
In the Library class I will:
Maintain a list of books
Create a way to add books to the collection
Create a way to register new patrons
Create a way to manage interactions with patrons (e.g. registering books and tracking borrowed books)
